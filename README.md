# Lunabotics

The official NASA Lunabotics GitHub repository for University of Minnesota Robotics.

This code base relies on [Linux's SocketCAN](https://www.kernel.org/doc/html/latest/networking/can.html) and [Foxglove](https://foxglove.dev/). Due to the SocketCAN dependency the code will only be able to run on Linux machines, or under WSL. Running on MacOS may be possible with full emulation, not just docker.


To get started with working on this code base see [[Setting up Computer for Development]].
